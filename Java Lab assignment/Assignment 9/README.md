# Assignment 9: Matrices: Rows and Columns

**Aim:** Visit the rows and columns of a matrix with nested loops to print, add and count its values.

## Tasks
1. Print the first and last row of a 3x3 matrix.
2. Calculate and print the sum of each column in a 3x3 matrix.
3. Count elements greater than 5 in a 3x3 matrix.

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `First row: 1 2 3`<br>`Last row: 7 8 9` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `Column 1 sum: 12`<br>`Column 2 sum: 15`<br>`Column 3 sum: 18` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Values greater than 5: 4` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 9/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
