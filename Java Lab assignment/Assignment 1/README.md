# Assignment 1: Hello World, Variables and Arithmetic

**Aim:** Print text, store values in variables and calculate with arithmetic operators.

## Tasks
1. Print "Hello World" and "Welcome to Java" on separate lines.
2. Display student details (roll, percentage, section, name) with labels.
3. Perform basic arithmetic operations (+, -, *, /, %) on two numbers (a = 17, b = 5).
4. Calculate and print area and perimeter of a circle (r = 7, PI = 3.14).

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `Hello World`<br>`Welcome to Java` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `Roll: 101`<br>`Percentage: 84.5`<br>`Section: B`<br>`Name: Asha` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Sum: 22`<br>`Difference: 12`<br>`Product: 85`<br>`Quotient: 3`<br>`Remainder: 2` |
| Task 4 | `Main.java`, `Main.class`, `Output.png` | `Area: 153.86`<br>`Perimeter: 43.96` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 1/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
