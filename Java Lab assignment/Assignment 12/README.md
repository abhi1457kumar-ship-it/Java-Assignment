# Assignment 12: Insertion Sort

**Aim:** Sort small arrays with insertion sort and count how many values are shifted.

## Tasks
1. Sort array {7, 3, 5, 1} using insertion sort.
2. Sort array {14, 3, 9, 21, 6} using insertion sort.
3. Count number of shifts during insertion sort on {6, 5, 4, 3, 2, 1}.

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `Sorted: [1, 3, 5, 7]` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `Sorted: [3, 6, 9, 14, 21]` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Shifts: 15` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 12/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
