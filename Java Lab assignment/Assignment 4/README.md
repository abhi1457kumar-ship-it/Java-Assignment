# Assignment 4: Writing Functions

**Aim:** Write functions with parameters and return values, and call them from main.

## Tasks
1. Write fact(n) and nCr(n, r) to calculate 5C2.
2. Write fact(n) and nPr(n, r) to calculate 5P2.
3. Write maxOf(a, b) to find the larger of two numbers (14, 9).

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `5C2 = 10` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `5P2 = 20` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Larger: 14` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 4/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
