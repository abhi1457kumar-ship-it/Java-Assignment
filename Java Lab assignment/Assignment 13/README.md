# Assignment 13: Strings: Methods and Palindromes

**Aim:** Use common String methods, reverse a word, check a palindrome and print substrings.

## Tasks
1. Demonstrate length(), indexOf('g'), and toUpperCase() on "Programming".
2. Reverse the string "Java" character by character using charAt in a loop.
3. Check if the string "racecar" is a palindrome.
4. Generate and print all substrings of "abc" from shortest to longest.
