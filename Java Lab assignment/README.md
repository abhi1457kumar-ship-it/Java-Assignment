## Structure & Execution

Each assignment folder contains separate task directories (`Task 1`, `Task 2`, etc.). Inside each task folder:
- `Main.java` — Source code
- `Main.class` — Compiled bytecode
- `Output.png` — Screenshot of terminal execution in VS Code

### Running Any Task
To compile and run any task:

```bash
cd "Assignment 1/Task 1"
javac Main.java
java Main
```

*(Note: Terminal screenshots in `Output.png` show the actual execution in the VS Code terminal).*
