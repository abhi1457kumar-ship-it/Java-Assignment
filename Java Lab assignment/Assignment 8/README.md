# Assignment 8: Matrices: Transpose and Row Sums

**Aim:** Create two-dimensional arrays, visit them row by row, and build a new matrix from one.

## Tasks
1. Fill a 3x4 matrix with 1 to 12 row by row and print it with trailing spaces.
2. Create and print the transpose of a 3x3 matrix with trailing spaces.
3. Calculate and print the sum of each row in a 3x3 matrix.

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `1 2 3 4 `<br>`5 6 7 8 `<br>`9 10 11 12` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `1 4 7 `<br>`2 5 8 `<br>`3 6 9` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Row 1 sum: 6`<br>`Row 2 sum: 15`<br>`Row 3 sum: 24` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 8/Task 1"
javac Main.java
java Main
```
