# Assignment 14: Characters: Counting and Positions

**Aim:** Use charAt to count vowels and a letter, and print each letter with its position.

## Tasks
1. Count vowels in the string "programming".
2. Count occurrences of the letter 'g' in "programming".
3. Print each character of "hello" on its own line with its index.

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `Vowels: 3` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `Count of g: 2` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `0: h`<br>`1: e`<br>`2: l`<br>`3: l`<br>`4: o` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 14/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*
