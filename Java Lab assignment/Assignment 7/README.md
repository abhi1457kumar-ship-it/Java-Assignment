# Assignment 7: Counting Steps and Complexity

**Aim:** Count the steps a program takes, and write its time complexity as a comment.

## Tasks
1. Count iterations of a loop from 1 to 10 with time complexity comment.
2. Count iterations of nested loops from 1 to 10 with time complexity comment.
3. Count halving steps for n = 1024 until 1 with time complexity comment.

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `Steps: 10` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `Steps: 100` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Halving steps: 10` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 7/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
