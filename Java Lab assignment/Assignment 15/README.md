# Assignment 15: StringBuilder Methods

**Aim:** Build and change text with StringBuilder, using append, insert and deleteCharAt.

## Tasks
1. Append " World" to StringBuilder "Hello" and print text and length.
2. Append numbers 1 to 5 with commas and delete trailing comma using deleteCharAt.
3. Insert "Hello " at index 0 of StringBuilder "Java" using insert().

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `Hello World`<br>`Length: 11` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `1,2,3,4,5` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Hello Java` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 15/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
