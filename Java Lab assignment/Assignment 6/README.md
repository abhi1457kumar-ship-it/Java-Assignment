# Assignment 6: Arrays: Reverse and Duplicates

**Aim:** Print an array in reverse order, find the smallest value, and check an array for repeated values.

## Tasks
1. Print array {10, 20, 30, 40, 50} in reverse order.
2. Find the smallest value and its index in array {2, 5, 1, 8, 3, 4}.
3. Check for repeated values in array {4, 9, 2, 9, 7} using nested loops.

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `50`<br>`40`<br>`30`<br>`20`<br>`10` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `Smallest: 1 at index 2` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Repeated value: 9` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 6/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
