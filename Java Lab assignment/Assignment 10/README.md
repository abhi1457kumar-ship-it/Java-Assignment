# Assignment 10: Switch and ArrayList

**Aim:** Choose a branch with a switch statement, and store and change a list of numbers in an ArrayList.

## Tasks
1. Print day of the week for day = 3 using a switch statement.
2. Create an ArrayList of integers, print the list, its size, and element at index 2.
3. Modify an ArrayList with set() and remove(), then print list and size.

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `Wednesday` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `[10, 20, 30, 40]`<br>`Size: 4`<br>`Item at index 2: 30` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `[10, 25, 30]`<br>`Size: 3` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 10/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
