# Assignment 2: Decisions and Loops with Numbers

**Aim:** Use if, else if and loops to make decisions and repeat steps with whole numbers.

## Tasks
1. Check whether n = 27 is even or odd using the % operator and if-else.
2. Determine grade for marks = 83 using an else-if ladder.
3. Check if year = 2024 is a leap year.
4. Calculate the factorial of 5 using a for loop.

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 2/Task 1"
javac Main.java
java Main
```
