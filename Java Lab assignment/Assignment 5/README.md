# Assignment 5: Arrays: Traversal and Counting

**Aim:** Create an array, visit every element with a loop, and add up or count the values.

## Tasks
1. Traverse array {3, 4, 5} and print each index and value.
2. Find the sum and largest value in array {12, 45, 7, 33, 21}.
3. Count elements greater than 10 in array {5, 12, 2, 14, 7}.

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `Index 0: 3`<br>`Index 1: 4`<br>`Index 2: 5` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `Sum: 118`<br>`Largest: 45` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Count greater than 10: 2` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 5/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
