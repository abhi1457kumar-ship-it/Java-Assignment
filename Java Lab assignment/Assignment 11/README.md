# Assignment 11: Bubble Sort and Selection Sort

**Aim:** Sort small arrays with bubble sort and selection sort, and count the swaps.

## Tasks
1. Sort array {5, 1, 4, 2, 8} using bubble sort.
2. Sort array {64, 25, 12, 22, 11} using selection sort.
3. Count number of swaps during bubble sort on {5, 1, 4, 2, 8}.

## Program Summary

| Task | Files | Expected Output |
|---|---|---|
| Task 1 | `Main.java`, `Main.class`, `Output.png` | `Sorted: [1, 2, 4, 5, 8]` |
| Task 2 | `Main.java`, `Main.class`, `Output.png` | `Sorted: [11, 12, 22, 25, 64]` |
| Task 3 | `Main.java`, `Main.class`, `Output.png` | `Swaps: 4` |

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 11/Task 1"
javac Main.java
java Main
```

*(Each task folder includes `Output.png` showing the program running in the VS Code terminal).*

**Submit:** One .java file per task (class Main) and a copy of its output.
