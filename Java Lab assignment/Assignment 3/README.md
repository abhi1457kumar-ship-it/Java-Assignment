# Assignment 3: Star and Number Patterns

**Aim:** Use a loop inside another loop to print stars and numbers in rows.

## Tasks
1. Print a 4x4 square of stars using nested loops.
2. Print a right-angled star triangle with 4 rows.
3. Print a number triangle with 4 rows (1 to n) with spaces.
4. Print an inverted star triangle with 4 rows.

## How to Run
Open terminal in the task folder and execute:

```bash
cd "Assignment 3/Task 1"
javac Main.java
java Main
```
